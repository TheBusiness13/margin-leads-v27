MarginBusiness Leads v5.0 — Revenue Command Center

Interface changes:
- Simplified SaaS sidebar: Overview, Leads, Opportunities, Campaigns, Inbox & Activity, Analytics and Settings.
- Replaces the marketing-style app header with a compact working header.
- Adds a live command centre with leads, qualification, follow-up and sending metrics.
- Adds dynamic next-best-action guidance.
- Adds live pipeline health and priority lead queue.
- Adds a pipeline status strip to the Leads workspace.
- Automatically hides the setup guide after leads exist.
- Renames Activity to Inbox & Activity and Performance to Analytics.
- Preserves the existing authentication, campaigns, AI, sending, providers, credits and Admin Console.

This is an interface and workflow release. It does not require a new SQL migration.
